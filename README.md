# Harness Tier List

Single-page tooling for ranking AI-coding harness patterns, sourced from public discourse (Anthropic docs, OpenAI Harness Engineering, Martin Fowler, HN threads).

- [`tier-list.html`](tier-list.html) — drag patterns between tiers (S/A/B/C/F) and bench, persists to localStorage, exports as markdown or JSON
- [`archive.html`](archive.html) — flat reference of all patterns, searchable + filterable by category

Vanilla HTML/CSS/JS. No build, no framework.
